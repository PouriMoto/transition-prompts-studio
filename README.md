# Kinetic Slam Wizard

ابزار ساخت پرامپت و پیش‌نمایش ترانزیشن Kinetic Slam (فارسی‌محور).

## فایل‌ها

| فایل | نقش |
|------|-----|
| `index.html` | پوستهٔ UI ویزارد (۶ مرحله) |
| `wizard.js` | منطق کامل: کاتالوگ، پیش‌نمایش GSAP، صدا، پرامپت، AI، خروجی |
| `theme.css` | تم فیروزه‌ای / تیره |
| `viewer.html` | کانواس پخش خروجی + دانلود HTML و پرامپت |
| `fonts/` | فایل‌های `.woff2` فونت کنار خروجی |
| `sample-project.json` | نمونهٔ پروژه برای Import |
| `transition-wizard-preview-only.html` | نسخهٔ قدیمی تک‌صفحه‌ای (اختیاری) |

## اجرا

1. پوشه را باز کنید.
2. `index.html` را در مرورگر باز کنید.
3. برای جلوگیری از محدودیت `file://` روی بعضی APIها، می‌توانید یک سرور ساده بزنید:
   ```bash
   python3 -m http.server 8080
   ```
   بعد بروید به `http://localhost:8080`.

## جریان کار

0. متن (هر خط یک صحنه)  
1. ترانزیشن‌ها + پیش‌نمایش زنده  
2. صدای ضربه + صدای زمینه (فایل جدا)  
3. سبک متن و فونت  
4. زمان‌بندی و پلاگین‌های GSAP  
5. پرامپت انگلیسی → کپی / بهینه‌سازی AI / نمایش در viewer / دانلود HTML

## پروژه JSON

- **خروجی پروژه JSON**: ذخیرهٔ state برای ادامهٔ کار یا اشتراک  
- **ورود پروژه**: بارگذاری همان فایل  
- **بازنشانی**: پاک کردن localStorage
